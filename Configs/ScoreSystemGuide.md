# 任务评分系统细则

## 总分构成
- **满分**: 100分
- **评级**: S (90+), A (80-89), B (70-79), C (60-69), D (60以下)

---

## 各任务类型评分细则

### 🔥 灾害检测任务 (DisasterDetection)

| 评分项 | 分值 | 说明 |
|-------|------|------|
| **时间得分** | 40分 | 基于完成时间与参考时间的比例 |
| **精度得分** | 40分 | 拍照距离、角度、所有火点是否找到 |
| **安全得分** | 20分 | 碰撞次数、是否坠毁 |

**时间评分细则**:
- 参考时间内完成: 满分
- 超时20%以内: 90%
- 超时40%以内: 70%
- 超时60%以内: 50%
- 超时更多: 30%

**精度评分细则**:
- 拍照距离在有效范围内: +10分/火点
- 正面拍摄(角度好): +2分/火点
- 找到所有火点: 满分

---

### 📦 货物运输任务 (Cargo)

| 评分项 | 分值 | 说明 |
|-------|------|------|
| **时间得分** | 50分 | 完成速度 |
| **安全得分** | 30分 | 飞行安全性 |
| **精度得分** | 20分 | 投放准确度 |

**安全评分细则**:
- 无碰撞: 满分
- 每次碰撞: -5分
- 坠毁: 0分

**精度评分细则**:
- 精准投放到目标区域: 满分
- 偏离目标: 按距离递减

---

### ✈️ 航点巡航任务 (Waypoint)

| 评分项 | 分值 | 说明 |
|-------|------|------|
| **时间得分** | 30分 | 完成效率 |
| **速度控制** | 40分 | 定速巡航精度（如启用） |
| **精度得分** | 20分 | 航点到达精度 |
| **安全得分** | 10分 | 飞行安全 |

**速度控制评分细则**:
- 偏差≤10%: 满分
- 偏差≤20%: 85%
- 偏差≤30%: 70%
- 偏差≤50%: 50%
- 偏差>50%: 30%

**速度计算方式**:
```
平均速度偏差 = Σ|当前速度 - 目标速度| / 采样次数
偏差百分比 = 平均偏差 / 目标速度
```

### 🔍 侦察任务 (Recon)

| 评分项 | 分值 | 说明 |
|-------|------|------|
| **时间得分** | 40分 | 完成速度 |
| **精度得分** | 40分 | 悬停稳定性和位置精度 |
| **安全得分** | 20分 | 飞行安全 |

**精度评分细则（悬停稳定性）**:
- 最大漂移≤0.5m: 40分 (完美)
- 最大漂移≤1.0m: 35分 (优秀)
- 最大漂移≤1.5m: 30分 (良好)
- 最大漂移≤2.0m: 25分 (及格)
- 最大漂移>2.0m: 20分 (勉强)

**悬停要求**:
- 到达侦察点后需悬停3秒
- 悬停期间位置偏移不超过阈值
- 偏移过大会重置计时器

## 通用扣分项

### 碰撞
- **每次碰撞**: -5分（从安全得分中扣除）
- **坠毁**: 安全得分清零

### 超时惩罚
根据任务类型的参考时间计算:
```
参考时间 = 任务难度系数 × 基准时间

时间得分 = (参考时间 / 实际时间) × 该项满分
```

## 实现细节

### 评分触发时机
1. **开始任务**: `MissionScoreManager.StartMission()`
2. **任务进行中**: 
   - 记录碰撞: `RecordCollision()`
   - 记录速度偏差: `RecordSpeedDeviation()`
3. **完成任务**: `MissionScoreManager.CompleteMission()`
4. **显示评分**: Success页面自动调用`MissionScoreDisplay`

### 数据流
```
MissionBase.BeginMission() 
    → ScoreManager.StartMission()
    → 任务进行中持续记录数据
    → MissionBase.CompleteMission()
    → ScoreManager.CompleteMission()
    → 计算各项得分
    → Success页面显示
```

## 配置建议

### 参考时间设置
- **DisasterDetection**: 火点数 × 30秒
- **Cargo**: 距离(m) / 8 + 60秒
- **Waypoint**: 航点数 × 20秒
- **Recon**: 侦察点数 × (悬停时间 + 10秒)
- **Patrol**: 巡逻圈数 × 航点数 × 15秒

### 难度调整
通过修改以下参数调整难度:
- 参考时间（影响时间得分）
- 精度阈值（影响精度得分）
- 速度容差（影响速度得分）
- 天气条件（影响整体难度）
